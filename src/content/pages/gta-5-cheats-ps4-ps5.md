## How do GTA 5 cheats work on PS4 and PS5?

GTA 5 cheats on PS4 and PS5 are button combos you enter during Story Mode, using the four face buttons (Cross, Circle, Triangle, Square), the four shoulder buttons (L1, R1, L2, R2) and the d-pad. The PS4 and PS5 versions use exactly the same codes, and both also accept the 1-999 phone numbers. The original 2013 PS3 release uses the same combos too.

This page is written for PlayStation players specifically, so every code below is spelled out in PlayStation buttons. No translating from Xbox letters, no squinting at symbols. If you're on Xbox, use the [GTA 5 Xbox cheats](/guides/gta-5-cheats-xbox/) page instead.

## GTA 5 on PS3 vs PS4 vs PS5: what changed for cheats?

| Version | Released | Button combos | Phone cheats | Returning-player vehicles |
|---|---|---|---|---|
| PS3 | 2013 | Yes | No | No |
| PS4 | 2014 | Yes | Yes | Yes |
| PS5 | 2022 | Yes | Yes | Yes |

The big jump was PS3 to PS4. The PS4 release added the in-game phone cheat numbers and the three returning-player vehicles (Duke O'Death, Kraken and Dodo), which have no button combo and can only be spawned by phone. The PS5 version, which arrived in March 2022, didn't change any cheats. It added visual and performance options, but your codes are exactly the same.

If you upgraded from PS4 to PS5, you don't have to relearn anything. Every code carries over.

## Does the DualSense change anything for GTA 5 cheats?

No, and that's a good thing. The DualSense has the same face buttons, shoulder buttons and d-pad layout as the DualShock 4, so every combo maps one-to-one. A few PS5-specific things are still worth knowing:

- **Adaptive triggers.** L2 and R2 have more resistance on the DualSense in some games. When a combo includes L2 or R2, press them fully and deliberately so the input registers. Half-presses are an easy way to break a sequence.
- **The d-pad is the d-pad.** The DualSense's d-pad is a single rocker. Press directions cleanly; a diagonal press can register as the wrong direction or nothing at all.
- **Button remapping.** If you've remapped buttons in the PS5's accessibility settings, the game sees the remapped inputs. A remapped Cross will break every cheat containing Cross. Reset to default if codes mysteriously fail.
- **Touchpad and Create button.** Neither is used in any GTA 5 cheat. Don't hit the Create button mid-combo unless you want a screenshot of your failure.

## Do GTA 5 cheats disable trophies on PS4 and PS5?

Yes. Any cheat disables trophies for the current play session on both PS4 and PS5. It's not permanent: reload a save or restart the game without cheating and trophies unlock again. If you're chasing the platinum, keep a clean save slot and only cheat on a separate one.

## PlayStation troubleshooting checklist

- **Used the stick?** Directions are d-pad only.
- **Too slow?** Enter the whole combo at a steady pace without stopping to check a guide.
- **In a mission or cutscene?** Some missions block cheats. Try free roam.
- **Mixed up Square and Circle?** It happens to everyone. Read the sequence out loud once before entering it.
- **In GTA Online?** Cheats only work in Story Mode.
- **Remapped buttons?** Reset PS5 accessibility mappings to default.

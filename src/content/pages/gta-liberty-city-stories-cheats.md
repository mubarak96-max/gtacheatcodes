## What are GTA Liberty City Stories cheats?

GTA Liberty City Stories cheats are short button combinations that unlock money, weapons, vehicles, weather changes and assorted chaos in Rockstar's 2005 prequel to GTA III. You play as Toni Cipriani in a 1998 version of Liberty City, and the cheat system works the same way it did on the PlayStation 2 trilogy: you punch in a sequence while you play, and the game confirms it with a message.

LCS launched on the PSP in 2005 and was ported to the PS2 in 2006. Both versions use the same codes, which makes this one of the easier GTA cheat lists to learn. Every single code is exactly eight inputs long, so once your thumbs know the rhythm, you can fire them off in a couple of seconds.

This is an unofficial fan page. It is not affiliated with Rockstar Games or Take-Two. Every code below was checked against at least two established GTA references before it made the list.

## How to enter GTA LCS cheats

1. Load your game and get into normal gameplay. On foot or in a vehicle both work.
2. Do not pause. Codes typed on the pause menu or map screen do nothing.
3. Press the eight buttons in order, at a steady pace. Use the d-pad, not the analog nub or stick.
4. Watch for the confirmation message. No message means a missed input, so start again from the first button.
5. Repeat stackable codes, like money or weapon sets, as many times as you like.

The easiest mistake on PSP is brushing the analog nub while you reach for the d-pad. If a code keeps failing, set the handheld down flat and enter it slowly.

## PSP vs PS2: what is different?

The button sequences are identical across both systems. The PSP simply has one left and one right shoulder button, so wherever a PS2 code calls for L1 or R1, the PSP uses L or R. None of the LCS codes use L2 or R2, which is why they translate so cleanly.

There are two practical differences:

- **Multiplayer codes:** LCS on PSP has a wireless multiplayer mode, and four cheats unlock extra multiplayer content. The PS2 port dropped multiplayer, so those codes have no effect there.
- **Jumping with Perfect Handling:** the traction cheat lets cars hop. Fan wikis note that on PSP you press Down on the d-pad to jump.

## Do cheats work in the LCS mobile port?

Rockstar brought Liberty City Stories to iOS and Android in late 2015 and early 2016. The mobile version has no keyboard and no on-screen button-code entry, so there is no built-in way to type these sequences with touch controls.

Fan references report that a Bluetooth controller does let you enter the PlayStation-style codes on mobile, using the usual mapping (Cross to A, Circle to B, Square to X, Triangle to Y, L1 to LB, R1 to RB). Results are not guaranteed to match the PSP: GTA Wiki, for example, notes the tank code spawns different vehicles in the mobile port. Treat mobile cheating as an experiment and keep a backup save.
